 切换说明 
 云开发平台套餐各类资源额度固定，难以满足业务灵活用量要求，为提高套餐资源使用率，平台推出 资源点计费模式 ，覆盖云开发个人版、标准版、企业版和企业高级版，用户可以在 套餐用量页 选择将云开发套餐资源切换为资源点计费模式。 
 历史微搭套餐和云开发旧套餐如需切换，先升级为云开发现网套餐（个人版、标准版、企业版和企业高级版），再进行资源点计费模式切换。 
 资源点获取方式 包括套餐配额、购买资源包和开启按量计费，资源点计费基准为1000点对应1元，其中不同套餐提供相应额度资源点，详细 额度见套餐配额 ，付费套餐支持加购资源包和开启按量计费。 
 资源点抵扣 顺序为 套餐资源点 &gt; 资源包 &gt; 按量计费 ，资源使用时按对应资源价值抵扣相应资源点，详细参考 资源点计费标准 。 
 说明： 
 切换资源点计费模式后，不支持切回原计费模式。 
 资源点计费模式下，各资源的用量统计存在更新周期（更新周期见 套餐用量页 ，统计延迟不超过 2 天），用量统计完成后才会进行资源点抵扣。抵扣时优先消耗当前生效套餐的资源点配额。 
 CloudBase 内置模型现已支持使用资源点计费，详细参见 Token 计费标准 。 
 免费体验 
 提供面向开发测试的免费体验环境，具体细则如下： 
 自2026年1月16日起，每个云开发账号，可使用一次性兑换码（兑换码领取方式详见 购买页 说明）创建一个免费体验版云开发环境。免费环境提供 3000 点/月 的资源点，供开发者功能体验。 
 正在使用云开发免费套餐的账号，不支持创建新的免费体验环境，原免费体验活动到期付费/销毁后，才可以创建新免费体验环境。 
 免费环境单次支持续费6个月， 到期前1个月内可以续费6个月 ，不支持自动续费。 
 如用户手动操作转为付费，免费环境也会转为付费环境，将会收到续费提醒。 
 免费环境暂不支持 加购资源包 和 开启按量付费 ，如有需要，请先升级为付费套餐。 
 注意： 
 免费环境存在一些功能使用限制，开发者如需使用，可在控制台上手动调整为付费环境。 
 免费体验续期政策仅适用于云开发控制台创建的体验版环境（微信体验版不适用）。 
 如识别到环境中存在资源使用异常，或其他违规行为，平台为防范安全风险，将先行采取限制措施，并在合理期限内通知。 
 如免费体验环境发生资源点调整、下线服务等变更，将提前通过微信公众平台、腾讯云等渠道下发通知，请开发者留意并关注。 
 免费体验版环境在 小程序发布 后，环境的到期时间变更为上线后的第15天，到期后环境进入停服隔离期，隔离期未转付费将销毁环境。长期使用可将免费环境转为付费环境，套餐有效期按新的计费周期生效。付费信息将提前通过腾讯云等渠道下发通知，请开发者留意并处理。

 Token 计费标准 
 大模型版本变动较为频繁，并且受底层资源供应影响，实际可使用的模型及其价格以 云开发控制台 展示为准。 
 不同模型消耗的资源点不同，高级模型具备更强的推理能力和更丰富的知识储备，但其输入和输出 Token 的处理单价更高，因此每处理相同数量的 Token 消耗的资源点更多。 
 说明： 
 缓存命中和缓存失效的策略是由底层大模型控制的，目前没有明确的规则。一般在请求上下文较大，短时间内持续请求才可能出现。 
 购买 Token 资源包后，请留意 凭证保管、访问鉴权与频率限制 ，如因凭证泄露、未鉴权调用或程序异常导致的 Token 消耗，仍将从 Token 资源包中正常扣减。 
 如有价格调整或旧版本模型下线，CloudBase 将在调整生效前通过官方公告等渠道提前通知。请关注 CloudBase 官方动态公告 ，并根据公告指引及时完成模型迁移或配置调整。

 资源单独变配加购方式 
 登录 云开发平台 ，选择需要购买的环境后，在套餐用量页单击升级套餐进入购买页，即可单独变配加购可发布应用数、内部用户数。 
 说明： 
 加购可发布应用数、内部用户数的资源周期跟随云开发环境套餐的生命周期。 
 例如用户购买了标准版套餐，标准版套餐有效时间为2025年6月1日至2025年7月1日，用户在2025年6月16日加购了100个内部用户数，则这100个内部用户数额度有效时间为2025年6月16日至2025年7月1日，有效时长不可选择。 
 加购金额计算规则和详细退费规则可见 套餐及资源包说明 。 
 可发布应用数、内部用户数变配后，若用量过剩可以随时进行降配退费（按剩余时长退还非抵扣代金券的实际支付金额），但降配时实际用量必须小于降配后总额度。详细退费规则可见 套餐及资源包说明 。 
 可发布应用数、内部用户数进行变配后，若后续套餐进行升级变配时需要同时支付可发布应用数、内部用户数在不同套餐版本下的差价。
