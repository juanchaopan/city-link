# 术语表

代码、文档和对话里统一用这里的叫法。代码里的命名用"英文"一列。

| 术语 | 英文 | 含义 | 不要叫成 |
|---|---|---|---|
| 首席规划师 | CityLink | 这款游戏的中文名和英文名；项目目录和代码标识使用 city-link | 城市连接 |
| 玩家 | Player | 用微信身份进入游戏的人，每人一座城市 | 用户（产品指标里除外） |
| 城市 | City | 玩家或系统在一个位置上拥有的城市 | 地图、关卡 |
| 城市群 | CityCluster | 由 64 个位置组成的 8×8 方格分组 | 区、服、服务器、大区 |
| 世界地图 | WorldMap | 显示城市群和各个位置状态的地图 | 大地图 |
| 位置 | Slot | 城市在城市群中的格子 | 坐标、地块 |
| 空位 | VacantSlot | 可以给新玩家使用的位置，包括系统城市的位置和可替换的流失城市位置 | 空地 |
| 地块 | Tile | 城市地图内的方格，每座城市 64×64 个 | 位置 |
| 地形 | Terrain | 位置上由服务端生成并固定的高度、地表和水体数据 | 地图、场景 |
| 高度层 | ElevationLevel | 地形的真实高度，共 4 层 | 海拔 |
| 平地 | Plain | 高度一致、适合建设的地表 | 空地 |
| 坡地 | Slope | 高度跨 1 层的地块，分为直坡和角形坡 | 斜面 |
| 鞍形地块 | SaddleTile | 对角高、另一对角低的少见地块，线路不能通过 | 马鞍地形 |
| 切坡路基 | CutBench | 直坡上的 45° 路线保持路面水平，两侧用挡墙和填方接地形的做法 | 路堤 |
| 新手走廊 | StarterCorridor | 河流不能穿过的一条通道，保证不修桥也能从市中心连到一个邻居 | 新手通道 |
| 山丘 | Hill | 高度较高、修路更贵的地表 | 高山 |
| 河网骨架 | RiverSkeleton | 城市群创建时确定的河流走向和边界口 | 河流地图 |
| 边界口 | RiverGate | 河流穿过共享边界的固定位置 | 河口 |
| 河流接口 | RiverSignature | 一座城市四条边上的河流类型，用来放置回归城市 | 河流签名 |
| 干流 | MainRiver | 3 格宽、可通航的河流 | 大河 |
| 支流 | Tributary | 1 格宽、不通航的河流 | 小河 |
| 湖泊 | Lake | 位于最低层的封闭水体，河流可以汇入 | 池塘 |
| 森林 | Forest | 可以花钱清除的地表覆盖 | 绿地 |
| 海岸 | Coast | 城市群外边界的海陆交界地形，可以建海港和国际港 | 海洋 |
| 矿产 | MineralDeposit | 工业区可以开采的地块资源 | 矿山 |
| 地形过渡 | TerrainBlend | 新地形贴合相邻已有地形的平缓变化 | 地形融合 |
| 城市群外边界 | ClusterEdge | 城市群 8×8 方格的外侧边界，是不可通行的远山或海岸 | 地图边缘 |
| 系统城市 | SystemCity | 占位的非玩家城市，提供贸易和预置线路，没有地形 | 机器人、NPC 城 |
| 相邻城市 | NeighborCity | 在城市群中共边的城市，最多 4 座 | 附近城市 |
| 相邻位置 | NeighborSlot | 地形过渡参考的 8 个周边位置，包含四角 | 相邻城市 |
| 普通道路 | Road | 最基础的道路，运力小，可以连外城 | 公路、马路 |
| 高速公路 | Expressway | 造价高、运力大的道路，只能从互通口进出 | 公路、快速路 |
| 互通口 | Interchange | 高速公路和普通道路相交的进出位置 | 立交桥、匝道口 |
| 桥 | Bridge | 线路跨越水体的设施，单段最长跨 5 个水体地块，不阻挡船只 | 高架 |
| 铁路 | Railway | 运力最大的陆上连接线路 | 高铁 |
| 陆上连接 | LandLink | 相邻城市之间通过普通道路、高速公路或铁路形成的连接 | 陆运、地面线路 |
| 连接点 | BorderPoint | 两座相邻城市共享边界上对齐的线路接口 | 边界口 |
| 内河码头 | RiverPort | 建在干流岸边、用于城市群内河运的码头 | 小码头 |
| 河运 | RiverShipping | 通过内河码头和连通河道进行的城市群内运输 | 内河航线 |
| 海港 | SeaPort | 海岸城市的大型港口，连接其他城市群的海港 | 码头 |
| 海运线 | SeaRoute | 两个海港之间的运输连接 | 海路 |
| 国际港 | InternationalPort | 海岸城市的大型港口，和外国市场贸易 | 外贸港 |
| 外国市场 | ForeignMarket | 系统模拟的跨国贸易对象，每日更新需求和价格 | 外国玩家 |
| 航线 | AirRoute | 两座建有机场、达到航空等级的城市之间的连接 | 飞线 |
| 好友航线 | FriendAirRoute | 通过微信邀请确认关系后建立、不受等级限制的航线 | 友谊线、绑定 |
| 分区 | Zone | 住宅、商业、农业或工业区域 | 区域 |
| 商品 | Goods | 城市产出并用于贸易的物品 | 资源、货币 |
| 资金 | Funds | 游戏内货币，不能兑换现金 | 金币、钱 |
| 出口配额 | ExportQuota | 玩家设定的自动出口上限 | 挂单 |
| 进口配额 | ImportQuota | 玩家设定的自动进口上限 | 求购单 |
| 贸易连接 | TradeLink | 两座城市之间可以自动流动货物的关系 | 订单 |
| 活跃连接 | ActiveLink | 至少一端在一小时内在线的贸易连接，定时任务只结算这类连接 | 在线连接 |
| 结算单 | SettlementBatch | 一次结算全部城市变化的记录，是结算的提交点 | 账单 |
| 入账 | LedgerApply | 把结算单的变化写入城市账本 | 到账（面向玩家的文案除外） |
| 城市账本 | CityLedger | 一座城市的资金、商品、等级和核定产出，和布局存在同一份文档 | 钱包 |
| 城市群租约 | ClusterLease | 让同一城市群的地形生成和骨架修改按顺序执行的短期锁 | 群锁 |
| 同步 | Sync | 客户端批量上传操作日志并取回权威数据 | 存档 |
| 操作日志 | OperationLog | 玩家建造操作的有序列表 | 指令 |
| 过境 | Transit | 贸易穿过第三座城市的线路 | 中转 |
| 过路费 | TransitToll | 途经城市按系统费率收到的费用 | 关税 |
| 城市等级 | CityLevel | 控制系统解锁的发展等级 | 玩家等级 |
| 解锁 | Unlock | 城市达到等级后获得的系统使用权 | 开启 |
| 离线结算 | OfflineSettlement | 玩家回来时按离线时长发放收益 | 挂机收益 |
| 流失玩家 | InactivePlayer | 30 天未上线的玩家 | 弃坑玩家 |
| 替换 | Replacement | 新玩家占用流失玩家或系统城市的位置 | 踢出 |
| 回归 | Return | 流失玩家重新进入游戏 | 复活 |
| 体验版 | TrialVersion | 邀请小范围玩家使用的微信小游戏内测版本 | 灰度版 |
| 公开测试 | PublicTest | 审核通过后面向所有微信用户开放的上线阶段 | 公测版 |
| 留存 | Retention | 新玩家在之后某一天再次进入游戏的比例 | 活跃率 |
