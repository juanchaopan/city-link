# 术语表

代码、文档和对话里统一用这里的叫法。“英文”一列是代码里的命名，括号里是 `docs/design/data-model.md` 里的表名或字段名。“出处”一列的“设计 §N”指 `docs/design/game-design.md` 第 N 节，“数据 §N”指 `data-model.md` 第 N 节，“目录 §N”指 `catalog.md` 第 N 节。

用词约定：

- 楼的星级一律说“星”，不说“档”或“级”。“档”说的是一组从低到高的选项：税率和预算的低、正常、高，专名“市场档”，以及密度、满意度、学历和收入的高低。
- “级”只用于城市等级、厂和机场的等级（一级厂、二级厂、国内机场升级成国际机场）。
- “天”是北京时间的现实一天，游戏里的一天写作“游戏日”。
