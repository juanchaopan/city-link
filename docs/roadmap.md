# 路线图

进度以 GitHub 的 issue 和里程碑为准，这里只记计划。

四个里程碑都属于第一版，第一版一次性上线（`product/vision.md`）。一个 issue 对应设计稿里的一整块，规则以 `design/` 下的设计稿为准。
