# 改规划和征收

- 日期：2026-10-31
- 级别：L2 需求变了；设计冲击 D0（分区和建造的业务代码还没有写）
- 来源：用户原话："如果这个地方已经是规划好住宅区，并且已经造出来了，那么你能重新规划成工业区吗？你的建议是什么？"；AI 建议的规则，用户回复"同意，按这个规则写进 REQ-004"

## 变了什么

已建成的分区可以直接划成另一种分区，不用先手动拆除。系统先显示要拆几栋楼、影响多少人和征收费，确认后扣费。里面的人在一个游戏日（现实 24 分钟）内陆续搬走，建筑拆除后新分区才开始发展。过渡期间这块地没有税收和产出。

地铁站、公共用地和新修的道路落到已有建筑上时，走同一套征收流程。连体物业整块处理。

## 为什么

城市长大后重新调整是规划游戏的乐趣之一，不能改会让玩家早期的错误无法纠正。费用和过渡期让改规划有代价，玩家不能靠反复改规划获利。一套规则覆盖全部占用已有建筑的场景，玩家只学一次，代码也只写一份。

## 影响

| 类别 | 内容 |

| 架构 | 无影响。征收是建造操作，走操作日志，服务端校验资金 |
| 代码 | 分区和建造的业务代码还没有写 |
| 数据 | 游戏未上线，没有数据要迁移 |

## 决定

- 改规划是一步操作，确认前能看到全部代价。
- 征收费按建筑价值和受影响的人数计算，未建成的地块不收，具体数值放在 Q-006。
- 居民优先搬进城里的空房，没有空房就离开城市。
- 过渡开始后不能撤销，费用不退。
- 过渡期间玩家离线时继续计时，回来时按经过的时间补齐。这一条和“覆盖已有分区”“过渡不能撤销”为 AI 补充的边界规则。
