# 落实三项探针的结论

- 日期：2026-10-30
- 级别：L2 需求变了；设计冲击 D0（项目还没有代码）
- 来源：地形河网、PixiJS 和云开发三项探针；用户原话："看广告费。有收入有赚就可以"

## 变了什么

云开发的成本前提改变：免费环境在发布后第 15 天到期，不是六个月。贸易结算改为只结算活跃连接，在线到账最多 5 分钟，两端都离线的连接等有人上线时补齐。成本上限跟随广告收入。

河网方案接受：80% 的位置有河，河网骨架在城市群创建时确定，回归城市按河流接口放置。直坡斜路用切坡路基，客户端竖屏，地图按 16×16 分块绘制。

## 为什么

探针模拟显示，最初的结算方案在 1000 日活时约 300 元/月，只结算活跃连接约 35 元/月。官方文档写明免费环境的到期规则。切坡路基让路面保持水平。

## 影响

| 类别 | 内容 |
|---|---|
| 需求 | 修改 REQ-003、REQ-014、REQ-020、REQ-022、REQ-027、REQ-033、REQ-036 |
| 架构 | ADR-0009 接受；更新 ADR-0001、ADR-0003 到 ADR-0006；ADR-0003 和 ADR-0005 仍是提议，等待真实环境验证 |
| 代码 | 项目还没有代码；河网探针归档在标签 `archive/spike-river-network`；`spike/client-pixi` 和 `spike/cloudbase` 保留，真实环境验证要用 |
| 数据 | 游戏未上线，没有数据要迁移 |

## 决定

- 选择只结算活跃连接；首笔贸易和进入游戏时立即结算。
- 成本上限：没有广告收入时 100 元/月；有广告收入后，上限取上月广告收入，且不低于 100 元/月。
- 直坡斜路用切坡路基，分层拼接绘制；地形、线路和水运素材估算约 277 张，不含建筑和高速互通口。
- 接受河网骨架和回归放置规则，直角、回环和长直段的判据由用户确认。
- 客户端竖屏，来源为 AI 建议，用户默认。

## 拆出的工作

项目还没有 GitHub 仓库和路线图，这次不拆 issue。真实环境验证由用户完成，步骤在两个探针分支的 `SPIKE.md`。
