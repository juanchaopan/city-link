# ADR-0009 河网骨架和水运

- 状态：已接受
- 日期：2026-10-30
- 相关需求：REQ-020、REQ-033、REQ-034、REQ-036、REQ-037、REQ-038

## 背景

大多数城市要有河流，河流尽量不断，并能作为城市群内的贸易通道。ADR-0001 的单格河流不保证整群连通。海边城市还要能建海港和国际港。

## 候选方案

| 方案 | 优点 | 缺点 | 适合条件 |
|---|---|---|---|
| 城市群创建时生成河网骨架 | 河流连通有保证，可以提前算出水运路线 | 骨架要和地形生成配合 | 河流是贸易通道 |
| 相邻城市逐个贴合 | 不用改算法 | 不保证连通和覆盖率 | 河流只是地貌 |

## 决策

- 城市群创建时，用种子生成河网骨架，记录干流和支流经过哪些位置，以及边界口的位置。地形仍然只在第一次被占用时生成，生成时按骨架铺设河道。
- 45% 的位置有干流，80% 的位置有河流。干流 3 格宽，可通航；支流 1 格宽，不通航。
- 边界口在城市群创建时固定，两边自然对齐。边界口偏移在 8 到 21 或 43 到 55 之间，对边的口至少错开 14 格。
- 每座城市有一条河流不能穿过的新手走廊，保证不修桥也能从市中心连到一个邻居。
- 内河码头建在干流岸边，通过河道连通的两座城市都建码头就能贸易，不必相邻。路线可以只用骨架计算，不需要已生成的地形。
- 途经城市按系统费率收过路费，系统城市按预置河道通过。桥不阻挡船只。孤立湖泊不算通航水面。
- 海港和国际港只能建在海岸城市。海港连接其他城市群的海港，国际港和系统模拟的外国市场贸易。

回归城市带着原地形放置：
1. 候选位置要满足：8 个相邻位置都没有地形，且外边界同类型。
2. 把这个位置四条边改成城市的河流接口，邻居的边跟着改。
3. 校验干流连通、河流都连到干流网、有河位置不低于 70%。
4. 选改动边数最少的位置，依次试 8 个开放城市群，都不行才新建。

修改骨架时要持有城市群租约。

## 证据

探针四轮，64×64、4 层，30 个城市群共 1920 座城市，机器为 AMD Ryzen 9 7940HS，Node v24.22.1。判据的通过线没有放宽。

| 判据 | 结果 |
|---|---|
| 硬失败 | 0，没有重试 |
| 接缝违规 | 0 |
| 有河位置 ≥70% | 79.7% |
| 干流连通 | 909 / 909 |
| 河流不断 | 3000 个河口断开 0 个 |
| 可建面积 ≥60% | 平均 78.2%，最小 60.9% |
| 全坡八方向连接点 | 首笔贸易和全部连通失败都是 0 |
| 生成耗时 P95 ≤100 毫秒 | 32 到 36 毫秒，P99 45 到 48 毫秒，最大 72 到 110 毫秒 |
| 明显直角 <0.5 个/100 格 | 干流 0.12，支流 0.13 |
| 回环 | 0 |
| 长直段 P95 ≤30 格 | 干流 25，支流 23，最大 36 |
| 回归城市 | 60 / 60，55 座进开放城市群；137 种组合全部成功 |
| 内河路线 | 900 条全部算出，平均 577 格，平均途经 6.7 座城 |
| 码头位置 | 909 座干流城市全部有，平均 103 个，最少 16 个 |
| 桥下通行 | 909 / 909 连通；桥挡船时只剩 55 / 909 |

直角、回环和长直段的算法见 `docs/adr/assets/river-spike.md`，由用户根据 `docs/adr/assets/river-confirm.png` 确认。

| 城市类型 | 数量 | 水体平均 | 可建面积平均 | 可建面积最小 |
|---|---|---|---|---|
| 干流城市 | 909 | 10.6% | 74.1% | 60.9% |
| 支流城市 | 621 | 4.2% | 80.6% | 64.1% |
| 无河城市 | 390 | 2.0% | 84.3% | 72.3% |

连片占用时，回归城市进开放城市群的比例在 10%、30%、50%、70% 占用率下分别是 96.1%、94.9%、90.2%、65.6%；随机散布时在 50% 占用率只有 7.2%，所以要保持 REQ-011 的新玩家优先靠近真人。

水运素材估算约 47 张：汇流口 4、河口 4、内河码头 8、海港 8、国际港 8、船 15。加上地形和线路约 230 张，合计约 277 张，不含建筑和高速互通口，没有实际制作。

CPU 被占满时，生成 P95 约 850 毫秒，最大约 2940 毫秒。云函数实际耗时由 ADR-0005 验证。

## 后果

- 好处：河流成为规划和贸易的核心，城市群更像一片完整的土地；路线不依赖已生成的地形。
- 代价：有干流的城市比无河城市平均少 10.2 个百分点的可建面积，要靠水运收益在数值上平衡；回归时可能改写骨架，要保护并发。
- 尚未验证：河流流向和上下游；水运的运力、时间和船只数量；多人同时进入时改写骨架的并发；2.5D 下河流和湖泊的观感；回归实测只用了连片 30% 一种占用率。
- 什么时候应该重新考虑：可建面积低于保底，或水运挤压陆路贸易。
