# ADR-0001 地形生成和线路规则

- 状态：已接受
- 日期：2026-10-30
- 相关需求：REQ-003、REQ-013、REQ-033、REQ-034

## 背景

位置第一次被玩家占用时，服务端要生成山丘、平地、河流、湖泊、森林、海岸和矿产，并和相邻位置完全接上。地形还要保证中心平地、可建面积和全部连接点，单次生成要足够快，存储要足够小。地形有真实高度，八方向线路在坡地和水面上的规则决定了 2.5D 素材量。

## 候选方案

| 方案 | 优点 | 缺点 | 适合条件 |
|---|---|---|---|
| 64×64，4 层，全部坡地和桥都走八方向 | 规划最自由，玩家不用记例外规则；起伏更明显 | 线路和地块素材估算约 214 张，不含建筑；直坡斜向未做渲染验证 | 优先保证规划感，能承担素材成本 |
| 64×64，4 层，只有角形坡和桥走斜向 | 约 190 张；探针已验证路线规则 | 超过一半坡地不能走斜线，规则不直观 | 想节省 24 张素材 |
| 64×64，4 层，坡上和桥只走水平、垂直 | 约 148 张；连接点全部修通已验证 | 坡上和过河失去斜线，和"保留八方向"不符 | 素材成本优先 |
| 64×64，3 层 | 素材少 15 张，可建面积多 2.6 个百分点 | 起伏变弱 | 地形只作为背景 |
| 128×128 | 城市更大 | P95 约 105 毫秒，真机压力未知 | 真机性能有余量时 |

## 决策

采用城市地图 64×64、4 层高度，全部坡地和桥都走八方向。

生成方法：
- 高度、森林和河流走向按全群坐标取噪声，相邻城市的纹理自然连续。
- 共享边界固定后，用切比雪夫距离的约束传播把相邻高度差限制在 1 层内。
- 共享边界的角点使用角点平台，避免两条边界在角上冲突。
- 河流只在最低层，从边界入口流向出口或湖泊，并避开共享边界。
- 河流把中心围住导致重试时，让河流改为汇入湖泊。

可建面积保底定为 60%，来源为 AI 建议，用户默认；探针 4 层最小值是 66.0%。

线路规则：转向只在平地发生，坡上和桥上保持方向；鞍形地块线路不能通过；桥单段最长跨 5 个水体地块。

## 证据

要回答的问题：在 8×8 城市群里按随机顺序首次占用位置时，能否生成合格的连续地形，高度取几层，需要多少素材。

判据由后台探针工作进程自行设定，用户拍板时选择了比素材判据更自由的线路规则，因此 150 张的上限不再适用。其余判据不变。

64×64 第三轮结果，3 层和 4 层各 1920 座城市，环境是 AMD Ryzen 9 7940HS 上的 Node v24.22.1：

| 指标 | 3 层 | 4 层 |
|---|---|---|
| 硬失败 | 0 | 0 |
| 边界、高度差、水位违规 | 0 | 0 |
| 可建面积 平均 / 最小 | 84.7% / 70.5% | 82.1% / 66.0% |
| 山丘 / 水体 / 森林 / 矿产 平均 | 20.9% / 2.3% / 19.6% / 0.9% | 21.2% / 2.3% / 19.6% / 0.9% |
| 首笔贸易 / 全部连通失败 | 0 / 0 | 0 / 0 |
| 生成 P50 / P95 / 最大 | 20.7 / 26.3 / 130 毫秒 | 15.4 / 21.9 / 87 毫秒 |
| 每城存储 gzip 平均 | 550 字节 | 592 字节 |

第三轮全部 6528 座城市都没有硬失败；没有角点平台时，3 层和 4 层各有 19 座和 31 座失败。

素材估算，三种线路各自计算，不含建筑，没有实际制作：

| 规则 | 每种线路增加 | 4 层总量 |
|---|---|---|
| 坡上四向、桥走正交 | 基线 | 148 张 |
| 角形坡走斜向，桥走斜向 | 14 张 | 190 张 |
| 全部坡地走八方向，桥走斜向 | 22 张 | 214 张 |

探针路线规则只测试了角形坡上的斜向。全部坡地走八方向是这个规则的超集，所以连接点不会变得更难修通；直坡斜向的素材和渲染效果没有验证。

证据文件：`docs/adr/assets/terrain-spike.md`、`docs/adr/assets/terrain-results.json`、`docs/adr/assets/terrain-cluster-L4.png`。探针代码归档在标签 `archive/spike-terrain`。

## 后果

- 好处：城市地形连续且各不相同，玩家在任何地形上都能用同样的八方向规则规划；存储小，生成快。
- 代价：线路和地块素材约 214 张，比最省方案多 66 张，增加了 2026 年 11 月 30 日目标的风险。
- 尚未验证：直坡斜向的渲染效果；回归城市带原地形落到新位置；微信云开发上的生成耗时；同一城市群并发生成的锁；河流外观仍偏生硬，湖泊偏小偏圆，要在正式实现时继续打磨。
- 什么时候应该重新考虑：素材制作进度威胁到上线时间；真机无法流畅渲染 64×64；微信云开发上单次生成明显超过 100 毫秒。
