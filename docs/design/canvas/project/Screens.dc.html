每个页面的编号和效果图一致（ui-screens/编号.jpg）。形式：整屏＝盖住地图、左上返回；小卡＝从顶部或底部按钮旁展开；气泡＝贴着地图上的东西；浮层＝小卡和气泡统称；页内＝不离开地图，只是地图上的一块状态。
