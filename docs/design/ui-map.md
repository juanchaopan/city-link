# 界面结构

本文说明玩家能看到的全部页面：屏幕上一直在的东西是什么，点了以后出现什么，怎么进下一层、怎么退回上一层、怎么回到地图。规则和数值的来由见 `game-design.md`，数据怎么存见 `data-model.md`，建筑见 `catalog.md`。

状态：2026-11-03 按 `game-design.md` 的最新结论整理，并配了页面的效果图，待用户确认。开发时按效果图实现页面和跳转；还没有效果图的页面按文字做，效果图补上后以图为准。

## 怎么看效果图

- 效果图都在 `ui-screens/` 里，按页面编号命名，比如 `ui-screens/B1.jpg`。
- 每张图左边是手机画面，右边是说明：编号、从哪个页面来、每个标注点的作用、点了去哪一张。
- 画面里深青底、金边的数字圆圈是标注，不是界面的一部分；红底白字的圆点才是游戏里的红点。
- 底图是美术探针的 2.5D 低多边形城市（64 格的样张，正式地图是 256 格），图里的数字和价格只是示意。图标用表情符号代替，正式图标按美术方向和第 1 节的图标表画。
- 示例数据里地区和城市不同名；头像都是系统动物头像。

## 1. 原则

这是游戏，不是信息系统。

| 原则 | 做法 |
|---|---|
| 地图是主角 | 除了地图，屏幕上只有顶部两行和底部三个按钮 |
| 数据画在地图上 | 用颜色、箭头、光圈和楼头上的小图标表达；最多浮一张小图表或几根进度条 |
| 不弹清单，不用文字解释原因 | 数字只用在钱、人口、价格和倒计时上；满意度用表情加一个固定的词；原因用图标和颜色。唯一的例外是城市结束画面上的一行短语 |
| 浮层贴着东西出现 | 点楼，楼头上冒一个气泡；点钱，钱下面展开一张小卡；不从底部拉半屏面板 |
| 改地图就在地图上改 | 改规划、征收、换等级都是拿工具直接画在原来的上面；气泡里没有“改规划”“征收”“升级”按钮；推土机点楼拆的是“分区 + 楼”，这也是取消分区的办法 |
| 关浮层不误触 | 浮层打开时，点浮层外面只关掉浮层，这一下不会同时点到地图；顶部四个数和底部三个按钮点了直接换成对应的浮层，不用先关；拖动照样平移地图，气泡跟着走 |
| 能回得去 | 页面按层叠起来：下钻一层，左上角出现返回，返回总是回到进入它的那一层（从小卡、气泡、站内信进去的视图和工具，返回回到那张小卡、那个气泡、那封信）。从整屏跳到地图上的东西时整屏关掉，返回回地图不回整屏。返回只有左上角一处，不用边缘滑动 |
| 一次一个 | 同一时间只有一个浮层；要紧的卡片排队，关掉一张再出下一张 |
| 单手能玩 | 常用按钮在屏幕下半部分，拇指够得到 |
| 一个图标一个意思 | 见下面的图标表 |
| 让开系统的东西 | 顶部按微信胶囊的位置和安全区排：第一行放在胶囊左边或下面，右上角留给胶囊，别的按钮也不放右上角；底部按钮、✓ ✕、撤销都在安全区以上；屏幕左右和底部各留约 16 px 的边，从这里按下不开始画，免得和系统返回手势抢 |

### 色板和按钮

| 用途 | 颜色 |
|---|---|
| 看视频 | 金色，带 ▶ |
| 主要动作（就这里、收下、领取、✓） | 绿色 |
| 次要动作 | 青色 |
| 破坏性动作（拆、结束、删除） | 红色，按住时有进度 |
| 征收、被换掉的楼 | 红色描边；红色只用在这两处 |
| 四类分区 | 住宅绿、商业蓝、工业黄、农业棕；需求条用同样四色，只用长短表示需求 |
| 水电燃气三根条 | 水蓝、电黄、燃气橙；满了外框变红 |
| 满意度五档 | 五色，最差一档用深橙，不用红 |
| 期限 | 金色；最后一天橙色 |
| 人口最多的那片路网 | 淡金光描边 |

### 数字和文字

- 顶部不带 ¥；超过 99,999 写“12.5万”，超过 1 亿写“1.2亿”；卡片里带 ¥，支出用“−”。
- 时间：1 小时以上写“3 时 12 分”，不到 1 小时写“12:05”；天数写“剩 N 天”；破产倒计时写现实时间，离线延期期间只显示在线剩余。
- 等级在界面上写“Lv7”。
- 正文不小于 14 号，次要文字不小于 12 号；点击区不小于 44 px，可以比图标大。设计以 360 宽为基准，12 字的城市名要放得下。
- 满意度的五个词全局统一，表情旁保留。

### 手势

手指移动不超过 8 px 算点，超过算拖。

| 手势 | 看地图时 | 建造模式里 |
|---|---|---|
| 单指拖动 | 平移地图 | 画线类工具（路、铁路、刷子、线路）从任何地方按下都是画，包括从已有的路上接出新路；放置类工具按在虚影上拖是微调，按在别处拖是平移；画到离屏幕边缘约 16 px 的边以内，地图自动跟 |
| 双指拖动 | 平移 | 平移；画到一半第二根手指落下，这一笔作废 |
| 捏合 | 缩放 | 缩放 |
| 点一下 | 选中、冒气泡 | 放建筑；再拖微调，门自动朝最近的路，不旋转 |
| 松手 | | 两端出可拖把手；一笔一段，确认前可从端点接着拉一段一起算价；确认后留在建造模式可接着画；撤销只对最后一笔 |
| 长按约 1 秒 | | 破坏性确认 |

### 镜头

- 四个缩放档：全城（看接口和邻居名）、街区（楼有轮廓）、街道（楼有细节、车可见）、特写（楼里的箭头和图标）。默认打开在街区档，对着上次离开的位置；右下角的回到全城按钮回到全城档、城市中心。
- 能拖出城市边界，最多到露出邻居一半，再往外回弹。
- 点东西时镜头不动；从站内信、气泡的按钮“飞过去”时镜头移动约 300 毫秒。
- 视图打开时一律用白天光照；主地图夜里只调暗并亮灯。

### 动效和声音

- 浮层打开关闭 150 毫秒；升级仪式不超过 3 秒；完工只在工地闪光，不出顶部小字。
- 有声音的动作：确认建造、完工、升级、收下钱、拆除、错误；环境声随缩放档和昼夜变。三个声音开关放一行。

### 等待和失败

要等服务端的页面和按钮用同一套样子，不弹窗：

- 整屏（地区、全国、站内信、参观）先画骨架，超过 1 秒出转圈；失败时中间一个断线图标加“重试”。
- 按钮点下变转圈，不能再点；失败时按钮抖一下回原样，旁边一个图标说明原因（断线、被拒的原因图标）。
- 10 秒没有回应按失败处理。

浮层有三种：

| 浮层 | 样子 | 用在哪 |
|---|---|---|
| 气泡 | 羊皮纸小卡片，带一个尖角指着地图上的东西，镜头动它跟着动；靠近屏幕顶部时翻到下面 | 点楼、路、站、厂、接口、工地、空地 |
| 小卡 | 从顶部的数字或底部的按钮旁展开，地图还在后面动 | 钱、人口、满意度、等级、建造托盘、视图托盘 |
| 整屏 | 盖住地图，左上角返回 | 站内信、地区地图、全国、我的城市、设置、升级仪式、开局、结束确认、城市结束、启动和非游戏状态 |

## 3. 启动和开局

- **加载页（L1）**：游戏名、进度条、城市小插画；恢复存档时多一句“正在恢复你的城市”。没网时，手机上有存档就用本地存档进 B1，城市名旁一个断网图标；没有存档就停在 L1，出“重试”。健康游戏忠告和适龄提示是否必须显示待核实。
- **隐私指引和用户协议（L2）**：在 A1 之前；拒绝时不能进游戏，弹窗可以重新打开。
- **没有城市时**：K1 就是首页。每次打开游戏都停在最近结束那座城市的 K1，直到点“开新城”。
- **位置预览（A1）**：只显示地形：山、河、湖、森林、海岸，还没有任何建筑；保证有一条能通航的河从这块地上穿过。胶囊下方靠右一张本地区 4×4 的小缩略图标出这块位置在哪；位置上原来留下的线头画在边界上，标“保护期后要接”。分到的位置给你留 30 分钟；进来时位置已被别人占了，就自动换成下一个空位，顶部写一句“原来的位置被占了”。可以看视频换位置，只在顺序最前面的约 4 个空位里换；换过以后，预览下面一排最多 3 个最近看过的位置缩略图，角上写还留几分钟，点一个免费切回。广告不可用时按钮写“换一个 · 今天还剩 N 次”，用完变灰。第一次进游戏没有返回；开新城时从 K1 进来，返回回 K1。被邀请进来的朋友跳过这一步。“就这里”是绿色。
- **取名（A2）**：最多 12 个字（表情按一个字数），有骰子随机起名；被邀请进来的顶部一行“你在〈邀请人〉旁边”；开新城时输入框里先填好上一座城市的名字，可以沿用或重起。内容安全不通过时输入框描红加一行小字；空名不能确认；等待时转圈；返回回 A1；键盘弹起时卡片上移。
- **新手引导（A3）**：五步：修路 → 造水厂和电厂 → 划住宅和工业 → 看楼长出来、收到第一笔税 → 升到 2 级。每座新城都出现，背景是 1 级空城。
  - 第 1 到 3 步遮住别的东西，只亮当前要点的按钮，手指动画示范。第 1 步在离通航河最近的平地上画一条推荐路线的虚影，手指沿虚影示范，画到别处也算完成；第 2 步只让沿河的格子发亮。
  - 第 4、5 步不遮罩，可以自由建造。徽章旁一个目标小签，按“楼 → 金币 → 徽章”逐个打勾；徽章发光时手指再出来指它。
  - 第 5 步：这个玩家第一次到 2 级时领升级奖励；第二座城起没有奖励，升级仪式结束就算完成。
  - 每一下点击和等待都有显示；胶囊下方一直有“跳过”，跳过要二次确认。中途关掉游戏，再打开从没完成的那一步接着走。
  - 结束时镜头拉远，一条船顺着穿城的河开过去，同时请求微信订阅授权（B5）。
- 三个入口的预览规则：新玩家可以看视频换，按地形加权；开新城可以看视频换，不加权；被邀请的不预览。

## 4. 主界面和偶尔出现的时刻

- 顶部：城市徽章（等级数字和金色经验环；满级时经验环金色满格）、城市名和游戏时间（点时间冒“第 N 年 N 月 N 日”）、信封、我的城市；第二行是资金、人口、满意度表情。保护期内城市名旁有嫩芽和剩几天；没网时城市名旁有断网小图标。
- 底部：建造、视图、地区三个大按钮；右下角一个回到全城的按钮。
- 地图上会自己出现的提示：在建工程的进度环、完工时的闪光、楼升星时的闪光（离线期间升了星的楼在打开游戏时一起闪）、对着你的线头的金色光环。地图固定一个方向，不能旋转。
- 离线补算时先画出城市，顶部一根进度条，这时只能看、不能造；补完进度条消失，再出 B2。
- 要联网的功能没网时置灰并带断网小图标：升级、修接拆线头和撤销线头、看视频和直接领取、地区和全国、站内信、好友、参观、改名、结束城市、开新城。恢复后自动同步，不弹窗。服务器维护时顶部一条“维护中，预计 HH:MM 结束”。
- 偶尔出现的时刻：

| 什么时候 | 页面 | 怎么关 |
|---|---|---|
| 打开游戏，离开超过 10 分钟；或者没网时打开、联网后第一次同步拿到离线记录（等没有浮层、没在画东西时出） | B2 离线收益：税的数字从零往上滚，下面小一号灰字“维护费 −¥N”，过路费单列“已到账”；离开超过 8 小时时画出冻结的小图标；看视频翻倍、延长（离开不到 8 小时不出延长），收下 | 点“收下”（绿色） |

## 6. 建造

- **建造托盘（D1、D2）**：底部按钮上方升起两排：上面一排是这一类的卡片，可左右滑（图标、造价、每天维护费；没解锁的带锁和等级，点了冒“Lv7 解锁”，能看价格；奖励建筑在城里现有的打勾变灰，拆了恢复，在建的显示进度环，只显示本气候能造的，地形不满足变灰带地形图标），下面一排是类别，推土机单独在最右。类别：道路和铁路（两车道、四车道、高速、铁路线、货运站、客运站）、分区、公共服务、水电燃气、公交地铁、港口机场、公园和垃圾（含清森林）、奖励建筑。匝道和立交不在托盘里。
- **“新”标签**：新解锁的卡片带“新”字，点过这张卡后消失；类别按钮上一个金色小点，表示里面还有带“新”的卡片；托盘里的“新”都没了，建造按钮上的金色小星才消失。视图托盘同样。“新”按城记，每座新城从头来。
- **建造模式**：顶部只留资金一格，其余收起；底部的按钮让开地图，左上角返回先回到 D1，再返回回到地图，没确认的一笔直接丢掉；工具名点一下换工具。虚影跟着手指，价格气泡跟着虚影：造价、每天维护费；落在森林上时价格和工期含清森林；要征收时写几栋、多少人，这些楼染红。钱不够时 ✓ 变灰，气泡写差多少，可以看视频补。

- **修线头（D3b）**：虚影第一次拖到离边界几格以内时问服务端一次，这一笔里记住结果。能接的边界格发亮，不能接的变灰带禁止图标。整条边都不能接时，边上画原因图标：嫩芽（对方在保护期）、已有接口的圈闪一下（这对位置已经有这种接口）、时钟加天数（冷却期）。方案没连到人口最多的那片、接了也不算接好时，边界照常发亮，虚影上一个断链图标，人口最多的那片描淡金光；✓ 仍然可以点，钱是玩家自己的。没网时边界不发亮、✓ 变灰。被对方抢先时工地变回空地、资金旁飘“+¥N”、镜头飞到对方接口打开 G2。
- **确认以后（D7）**：屏幕下方一个 10 秒倒数的撤销按钮，点了全额退款、按原样恢复；撤销只对最后一笔。倒数完之前按钮一直在，退出建造模式也在。
- **工地（D8）**：在建的东西上有进度环；点它冒气泡：剩余时间、看视频加速（剩余不到 30 分钟写“立即完成”，否则“−30 分钟”）、取消（按住约 1 秒，写退回多少钱）。自己长的楼也有进度环，但没有这两个按钮。
- **拆除（D9、D10）**：
  - 点一下只是选中，描红并冒气泡：点路选中两个路口之间的一段；点楼选中这栋楼的分区格，拆的是“分区 + 楼”。沿路拖选中连续的几段；在分区上拖出矩形，选中里面的分区和楼。
  - “拆”按一下就拆，选中的一次拆完，10 秒内一起撤销；撤销之前，拆的东西在城里照旧起作用。
  - 拆的路段会让某个接口变成没接好时，气泡里画出拆了以后的样子，分三种：对方有线头，你这边亮起光环和“7 天”；对方没线头或对面空白，接口消失；对方正在接，对方完工后你要接回来。这三种“拆”都要按住约 1 秒；边界外按 G4 的灰色邻居画面画；拆边界段要联网。

## 9. 邻居和边界接口

### 地图四边（G1）

每条边的中点外侧写着邻居的名字和头像；没人的位置写“空白”。边上画出每个接口：

| 状态 | 样子 |
|---|---|
| 两边都接好 | 实线绿圈，车或火车一直在过 |
| 你修出去、等对方接 | 灰色虚线圈，旁边一个“⋯” |
| 对方修到边界、等你接，期限在走 | 金色光环一圈圈往外扩，旁边“剩 N 天”；最后一天写小时、变橙 |
| 对方修到边界、期限还没开始（保护期、等级不够、前面还有一个期限） | 金色光环不扩，小签写“保护期后”“Lv7 后”或“排队中” |
| 你已开工接，期限冻结 | 金色光环停住，旁边进度环 |
| 对方拆了他那头 | 你这边是“⋯”：期限算在他那边 |
| 你拆了你那头 | 你这边是金色光环和天数：期限算在你这边 |
| 两边都没接好 | 两边各自的光环 |
| 对着空白位置 | 灰色虚线圈，不带“⋯” |
| 对着空白位置，但位置上有旧线头 | 灰色虚线圈加一个旧线头的小图标 |
| 邻居是刚建的城市 | 名字旁一个嫩芽和剩几天的保护期，期间不能往那边修 |
| 跨地区口岸 | 圈外一个地区的小标记 |
| 河流进出城市的地方 | 小船图标；河跨地区的地方也一样，没有口岸标记 |

### 点接口（G2、G3、G5、G6）

- 对着你的线头（G2）：气泡写邻居、线路类型和剩几天（期限没开始时写原因，已开工时写进度，没网时写断网）；地图上你城里人口最多的那片路网描一圈淡金光，接到这片才算接好。
- “去接上”按对面是什么拿起对应的工具：铁路线头拿起货运站，直接进入放货运站（G3），只有线头旁边能接的格子发亮；高速线头拿起两车道，拉到线头边上自动出匝道（D4）；对面是匝道或货运站时拿起高速或铁路，等级不够写“Lv7 后”。没有同意和拒绝按钮。钱不够时看视频补。方案接了也不算接好时，和修线头一样：虚影上一个断链图标，人口最多的那片描淡金光，✓ 仍然可以点。每个玩家第一次“去接上”是一步引导。
- 修线头和接线头都要联网；没网时“去接上”和修到边界的工具置灰。
- 接好以后光环停下，变成实线绿圈，镜头上闪一下。
- 两边都接好的接口（G5）：气泡写每天经过多少货、收了多少过路费。
- 你修出去的接口（G6）：气泡写邻居头像、线路类型和对方那边的状态小签（剩几天、保护期后、排队中、开工进度）。对着空白的接口，气泡写“空白位置，有人入住后算请求”；位置上有旧线头的，多画一个旧线头的小图标。
- 要断开只能拆（D10）。

### 看邻居（G4）

把地图拖过边界，能看到邻居城市的灰色画面：地形、河、铁路、高速公路，是对方最近一次同步的样子。邻居的头像和名字浮在中间；点头像冒气泡：加好友（已申请时写“已申请”），是好友时多一个“实地参观”。D4、D10、F7、G3 里画到边界外的部分都按这个灰色画面画。

## 10. 站内信

点信封，整屏打开，两个页签。这是唯一会列清单的地方。

- **待处理（H1）**：要接的线头、好友申请、升级奖励。线头的“去看看”关掉整屏，镜头飞到接口打开 G2；好友申请同意或拒绝；升级奖励领取或看视频翻倍后领取，领过的移到底部变灰。计数只数没处理的，信封上的红点也只数这一页。
- **通知（H2）**：工程完成（只有工期超过 10 分钟的）、资金为负、破产保护、邻居接好了你的线头、邻居拆了接口、邻居结束了、新邻居入住、旧线头开始算请求、保护期明天结束、系统公告。每封一个图标、一行字（“消防站完工”）和时间，点了镜头飞到相关的地方；系统公告点了原地展开全文。未读的左边一个点；有未读时页签上一个灰色小点，信封上不显示。
- 空信箱有小插画。信保留 30 天，待处理和没领取的不删。要接的线头主要靠地图边界的光环和信封上的红点提醒，站内信是备份。

## 11. 地区、全国和参观

- **地区（I1）**：本地区 4×4 个位置，地图占满中间，可拖可缩放，按地形着色，河网从地区里流过；城市画成小天际线，越高等级越高，城市名不小于 12 号，点击区按格子中心 44 px；你的城市金框，好友带头像，保护期内的带嫩芽；连通的城市之间画线（灰色高速、棕色铁路、蓝色河）。
  - 点一座城市冒气泡：头像、名字、等级，“看看”（灰色画面）；不是好友的多一个“加好友”（已申请时写“已申请”），好友多一个“实地参观”。
  - 紧挨你的空位上一个 ＋，点了邀请好友，调起微信分享卡片。已经留给邀请的空位画灰色头像占位和剩几天，没有 ＋；每人 3 个留位用完时其余的 ＋ 变灰，点了冒“3/3”。
  - 底部一排好友头像写昵称，不分地区：点头像冒出他现在的城市和历史城市的缩略图，点一张就去参观。右下角一个“全国”按钮。地区里只有你一个时，空位照常画，不另出提示。
- **全国（I2）**：整个国家：各地区的形状、名字和气候，全国河网，口岸，你的地区描金边；只在真有海岸的地方画海，海外面是外国市场。点别的地区冒小签：地区名、气候、城市数。返回回 I1。
- **参观模式（I3）**：顶部一条左边是返回（回到来的地方），中间写“正在参观谁的城市”，右边是对方的头像，点了冒和 G4 一样的气泡（加好友、已申请、实地参观）；只能看，不能操作；顶部的数和底部的按钮隐藏；点楼的气泡里没有税和钱。“看看”和历史城市用灰色画面，实地参观好友是彩色的。
